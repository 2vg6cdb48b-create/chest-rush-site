# Project notes

This repo is the GitHub Pages site for NG Plumbing & Heating's apps. `main` is what gets published.

- `van-stock-app/`: Van Stock (Expo). Its website build is in `van-stock/app/` (`npm run build:site`).
- `gas-safety-app/`: NG Gas Records, for landlord gas safety records (CP12) (Expo). Its website build is in `gas-records/app/` (`npm run build:site`).

## Working preferences

- After every change to Van Stock or NG Gas Records, rebuild the website copy, then open a pull request from the working branch and merge it into `main` straight away so it goes live, without asking first.
