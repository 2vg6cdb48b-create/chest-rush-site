# Manual finder

Search UK gas boiler manuals by make, model or GC number. Save the PDFs you download to your phone, note the useful pages, and keep notes per boiler.

Open it at the GitHub Pages address, then in Safari tap Share → Add to Home Screen.

Saved manuals, page shortcuts and notes are kept on the phone (browser storage), not in this repo. GC numbers are taken from manufacturers' manuals and websites; each boiler page links to its source. Always check the boiler's data badge.
